# MindGames (módulo completo)

Hub standalone con los 2 minijuegos del módulo MindGames.

## Cómo ejecutarlo
Desde esta carpeta:

```bash
npm install
npm run dev
```

## Juegos
- El Semáforo Loco (`src/MindGames.tsx`)
- RainMath (`src/RainMathGame.tsx`)
- Hub (`src/App.tsx`)
- Estilos (`src/styles.css`)

## Cómo devolver cambios a la app
1. Edita y prueba aquí.
2. Reintegra en `src/components/MindGamesPanel.tsx` y/o `src/components/RainMathGame.tsx` (+ CSS en `src/index.css`).

Los stubs no van a la app.
